Multi Persona Uploader · 시행일 2026년 10월 28일

Multi Persona Uploader(이하 "이 도구")는 맵핵트레이딩 채널 운영자가 자기 컴퓨터에서 쓰는 업로드 도구입니다. 이 도구는 운영자 본인의 유튜브 채널과 인스타그램 계정에만 연결되며, 다른 사람의 정보를 수집하지 않습니다.

1. 받는 정보

  • 운영자가 승인한 구글(유튜브)·인스타그램 계정의 접근 토큰
  • 업로드할 채널과 계정의 식별자(채널 ID, 계정 ID)
  • 업로드한 영상의 결과 정보(영상 ID, 게시 상태)

2. 쓰는 목적

운영자가 확인하고 승인한 영상을 운영자 본인의 채널과 계정에 올리고, 제목·설명·공개 상태를 설정하는 데만 씁니다. 광고, 분석, 프로필 작성에 쓰지 않습니다.

3. 보관

토큰은 운영자의 컴퓨터에만 암호화해 보관하며 외부 서버에 저장하지 않습니다. 업로드에 필요한 기간 동안만 보관하고, 연결을 끊으면 지웁니다.

4. 제3자 제공

받은 정보를 팔거나 다른 사람에게 넘기지 않습니다. 영상을 올리기 위해 Google(YouTube)과 Meta(Instagram)의 API에 요청을 보내는 것 말고는 정보를 전송하지 않습니다.

5. Google API 데이터

이 도구가 Google API에서 받은 정보를 쓰고 전송하는 방식은 Limited Use 요건을 포함한 Google API Services User Data Policy를 따릅니다.

6. 연결 해제와 데이터 삭제

  • 구글: myaccount.google.com/permissions에서 Multi Persona Uploader의 접근 권한을 삭제할 수 있습니다.
  • 인스타그램: 인스타그램 앱 → 설정 → 웹사이트 권한(또는 앱 및 웹사이트)에서 연결을 해제할 수 있습니다.
  • 삭제 요청은 아래 이메일로 보내면 30일 안에 이 도구가 보관한 토큰과 식별자를 모두 지우고 회신합니다.

Privacy Policy (English)

Effective October 28, 2026.

Multi Persona Uploader ("the tool") is a personal upload tool run by the operator of the 맵핵트레이딩 (Maphack Trading) channel on the operator's own computer. It connects only to the operator's own YouTube channels and Instagram accounts and does not collect information about anyone else.

Information received

  • Access tokens for the Google (YouTube) and Instagram accounts the operator authorized
  • Identifiers of the target channels and accounts (channel ID, account ID)
  • Results of uploads (video ID, publishing status)

Use

The information is used only to upload videos the operator reviewed and approved to the operator's own channels and accounts, and to set their title, description and visibility. It is not used for advertising, analytics or profiling.

Storage and sharing

Tokens are stored encrypted on the operator's computer only, never on an external server, and are deleted when the connection is removed. The information is not sold or shared with anyone. Apart from the API requests to Google (YouTube) and Meta (Instagram) needed to upload videos, no information is transmitted.

Google API data

The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and data deletion

Revoke Google access at myaccount.google.com/permissions and Instagram access in the Instagram app's website permissions settings. Send deletion requests to the address below; all stored tokens and identifiers are deleted and the request is answered within 30 days.
